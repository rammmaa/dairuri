# Map Home Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the first Expo React Native map home screen from the provided Figma/Tailwind reference.

**Architecture:** Scaffold a TypeScript Expo app, add design tokens, fixture data, focused reusable components, and a `MapScreen` that composes the map preview, filters, bottom sheet, cards, and bottom nav. Configure the Naver map SDK key through Expo config while keeping REST secrets out of client code.

**Tech Stack:** Expo, React Native, TypeScript, `@testing-library/react-native`, `jest-expo`, `lucide-react-native`, `react-native-svg`, `@mj-studio/react-native-naver-map`.
